## Purpose

This audit records the current state of runtime, generated, legacy, and
benchmark-support artifacts under:

`gaia-bootstrap-poc/benchmark/collaborator/`

No deletion or relocation is authorized by this document alone.

### `skill-test-matrix.yaml`

This file contains the original skill-to-test mapping for the Collaborator
Home Assistant benchmark.

It currently uses the older six-test naming:

- `C01_intent_recognition`
- `C02_tool_selection`
- `C03_home_assistant_action`
- `C04_invalid_entity`
- `C05_ambiguous_request`
- `C06_multiturn_state`

The active v0.3 benchmark uses domain-specific golden contracts under
`domains/`.

Decision:

- `historical/reference candidate`
- retain for now
- do not silently reinterpret it as the canonical v0.3 benchmark contract
- reconcile its lineage with Git history before archival or removal

## Legacy repository references

`oldRepoReferences/` is intentionally retained.

Current documentation and agent instructions explicitly classify it as
historical/reference-only material.

It is therefore outside the scope of this cleanup.

Do not move or delete its contents as part of the Collaborator consolidation.

## Decision rules

Before removing or relocating any artifact:

1. check Git history;
2. check active references;
3. determine whether the artifact contains information absent elsewhere;
4. identify the canonical replacement, if any;
5. record the decision in a dedicated cleanup commit.

Unknown or historically useful material remains untouched.
