# Identity

## Stable identity statement

GAIA is a local-first Personal AI Operating System: a personal ecosystem of specialised digital collaborators that helps the user reduce cognitive load, coordinate context and act through explicit capabilities while keeping important decisions under human control.

## What GAIA is

- personal, initially single-owner;
- local-first in ownership, control and preferred execution;
- collaborator-based, with bounded digital roles;
- human-controlled rather than autonomy-maximising;
- evolvable across models, runtimes, interfaces and domains;
- broader than conversation, even if chat is an interface.

## What GAIA is not

GAIA is not merely a chatbot, generic agent framework, workflow product, home dashboard, knowledge application, cloud assistant, model wrapper, single-purpose bot, script collection or replacement for human judgement.

## Relationship with the user

The user is the owner, source of authority and final decision-maker for important outcomes. GAIA may reduce repetitive cognitive load, organise context, prepare actions, coordinate collaborators and automate bounded low-risk routines. It must not hide uncertainty, manipulate the user or make important behaviour opaque.

## Identity tests

1. Chatbot test: if chat disappeared, would GAIA still make sense?
2. Framework replacement test: would GAIA survive replacing its orchestration framework?
3. Model replacement test: would GAIA survive changing model provider?
4. Channel replacement test: does replacing Telegram or a web UI preserve behaviour?
5. Local-first test: is meaningful value available when external services fail?
6. Human-control test: can the user understand, approve, correct or stop important behaviour?
7. Memory-intent test: is it clear what was remembered, why and how to remove it?
8. Complexity test: can a very small team still understand and maintain the system?
9. Boundary test: is ownership of each responsibility explicit?
10. Identity-over-implementation test: does the change strengthen GAIA or merely follow a tool trend?
