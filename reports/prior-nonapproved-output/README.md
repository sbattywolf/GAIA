# GAIA Documentation Repository

GAIA is a local-first Personal AI Operating System: a personal ecosystem of specialised digital collaborators that helps its owner reduce cognitive load, coordinate context and act through explicit capabilities while retaining human control.

## Repository roles

- `reference/`: current working truth. Stable enough to guide decisions, but still reviewable.
- `sprint-01/`: research, reuse analysis and first architectural critique.
- `sprint-02/`: stress testing, patterns, bottlenecks, lessons and synthesis.
- `adr/`: future decisions. Empty decisions are represented by a template, not invented conclusions.
- `incubator/`: ideas that are not approved roadmap work.
- `assets/diagrams/`: PNG figures plus Mermaid source in the documents.
- `reports/`: recovery, provenance and replacement guidance.
- `prompts/`: restart prompts for future research sessions.

## Status and provenance

This is a reconstructed replacement pack. Current reference artefacts found in Microsoft 365 were preserved in meaning. Missing Sprint files were reconstructed from the surviving model, architecture guide, roadmap, image prompt and the conversation history. They are not claimed to be byte-for-byte copies of the lost files. Every reconstructed Sprint document is marked accordingly.

Start with `reference/IDENTITY.md`, then `reference/GAIA_MODEL.md`, then the two Sprint folders.
