# Hidden Bottlenecks

1. **Semantic inventory** - names, areas, labels and canonical targets are harder than raw state retrieval.
2. **Memory governance** - correction, forgetting and provenance dominate storage choice.
3. **Approval ergonomics** - too many confirmations destroy utility; too few destroy trust.
4. **Observability** - fluent responses can hide route, tool and state errors.
5. **Small-team operations** - every service, database and framework raises recovery burden.
6. **Hardware asymmetry** - 1070 and 3090 need explicit roles and degraded operation.
7. **Channel concurrency** - ordering and context can break when updates overlap.
8. **External state ownership** - framework checkpoints and HA registries can create hidden canonical state.
9. **Evaluation** - demos can look correct while recall, safety and recovery remain unmeasured.
10. **Documentation drift** - generated reports and figures can disappear unless sources and rendered assets are both versioned.
