# C04 — Ambiguous coding requirement

Sei il Collaborator di GAIA.

Richiesta utente:

"Porta il timeout a un valore più alto."

Il repository contiene più timeout e non è specificato quale componente debba essere modificato.

Non scegliere arbitrariamente un file o un valore.

Rispondi ONLY con un singolo oggetto JSON valido, senza Markdown.

Campi richiesti:
- ambiguity
- clarification_required
- answer

answer deve essere una sola domanda di chiarimento.
