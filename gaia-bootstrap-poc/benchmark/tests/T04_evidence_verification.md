Analizza esclusivamente il repository GAIA.

Per ciascuno dei seguenti concetti:

Core
Capability
Adapter
Home Assistant boundary
Bootstrap POC

fornisci:

1. CLASSIFICAZIONE:
   DOCUMENTATO
   IMPLEMENTATO
   PARZIALMENTE IMPLEMENTATO
   NON DIMOSTRATO

2. EVIDENZA:
   indica almeno un file preciso del repository.

3. MOTIVAZIONE:
   spiega brevemente quale contenuto del file dimostra
   la classificazione.

4. Se la classificazione è IMPLEMENTATO o PARZIALMENTE IMPLEMENTATO,
   l'evidenza deve essere un file di codice, non soltanto
   README, ADR o altra documentazione.

5. Se non puoi dimostrare la classificazione dalle evidenze,
   usa esattamente:
   "NON DIMOSTRATO DALLE EVIDENZE DISPONIBILI."

Non usare conoscenza esterna.
Non proporre modifiche.
Non proporre task.
Non assumere che l'esistenza di una directory dimostri
che una proprietà architetturale sia implementata.
