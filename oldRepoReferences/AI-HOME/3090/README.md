# Zeus Brain 3090

Draft structure for on-demand coding and Home Assistant engineering.

- `agents/`: specialised policies
- `jobs/`: queued work items
- `workspace/`: disposable checkouts
- `artifacts/`: proposed dashboards/automations/patches
- `openwebui/`: deployment notes
- `mcp/`: MCP client/server configuration examples without secrets
- `scripts/`: startup, shutdown and health checks

No automatic live Home Assistant modification in the initial phase.
